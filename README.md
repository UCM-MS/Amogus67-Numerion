# Numerion

Robíme matematickú hru pre 7. až 9. ročník ZŠ. Tím Amogus.

## Týždeň 1

Za prvý týždeň odovzdávam matematické jadro. Vyberá otázky podľa ročníka a vyhodnocuje odpovede. V každom ročníku je zatiaľ 36 úloh.

Scénu a rozhranie pripojíme pri spoločnom zostavení. Zatiaľ sa dá spustiť test jadra cez .NET 10 SDK.

```powershell
dotnet run --project unity/Tests/MathHarness/MathHarness.csproj
```
